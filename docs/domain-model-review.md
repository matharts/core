### 已确认的设计问题与此前结论纠偏

**[P2] `HiddenStems` 的槽位排序与传统“余气”概念没有分开定义。** [branch.rs:38](/Users/lzm0x219/Code/github.com/matharts/core/src/branch.rs:38) 把 `secondary`、`residual` 直接解释为中气、余气，但当前四季支依次填入丑癸辛、辰乙癸、未丁乙、戌辛丁。因此按传统季节承接意义的余气，四项都落在 `secondary`，不在 `residual`。例如《三命通会》卷二《论地支》明确把辰中乙称作余气；《滴天髓阐微》任氏论衰旺又区分丙丁得未、甲乙得辰、庚辛得戌、壬癸得丑的余气，与各自墓库。这说明**古文中的余气类别，不能直接等同于当前第三槽位**。

这是**语义契约未定准**，不是已证明的藏干成员错误，也不能据此擅自交换四组数据。若 API 表示选定的排列，应写明每个槽位的排序标准，并说明它不等于按季节来源划分的余气；若要表达古籍的气类，须先确定统一定义，再讨论映射。保留现有标识符。[《三命通会》卷二](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷02)、[《滴天髓阐微》衰旺](https://zh.wikisource.org/zh-hant/滴天髓闡微)（后者当前转录有重复句，本轮只用其清楚列出的四组作交叉证据）。

**[P2] 六破的来源和适用范围尚未写入方法契约。** [branch.rs:222](/Users/lzm0x219/Code/github.com/matharts/core/src/branch.rs:222) 六对配对与《六壬大全》卷三《破》的原文转录一致，包括寅亥、巳申，且原文说明反向亦然。然而《古今图书集成》艺术典第601卷所录《破杀》只取另外四对，明确排除寅申巳亥；更早《五行大义》的“冲破”又是在六冲对位上细分，并非当前六破表。故当前表有传统依据，**不能视为所有文献中“破”的唯一含义**。对跨数术 Core，应限定本方法采用的六对关系并列出处，不需要改名、删配对或把别书的破杀规则强塞进来。[《六壬大全》卷三《破》原文区](https://libokang.com/zh-hant/guji/liuren/六壬大全/3/)、[《古今图书集成》艺术典第601卷《破杀》](https://zh.wikisource.org/wiki/欽定古今圖書集成/博物彙編/藝術典/第601卷)、[《五行大义》卷二《论冲破》](https://www.zinbun.kyoto-u.ac.jp/~takeda/kyoudou/gogyou/gogyoutaigi/gogyo_gogyo_02_g.html)。

**撤回此前把三刑两组名称倒置认定为唯一错误的结论。** [branch.rs:250](/Users/lzm0x219/Code/github.com/matharts/core/src/branch.rs:250) 当前寅巳申称无恩、丑戌未称恃势，符合《三命通会》卷二正文一说；同一篇随后又记《三车一览》反用两名，并认可其解释。当前版本可以保留，原版本也有文献依据。正确的审查结论是“采用哪一说应说明”，而不是“原名必错”。这只涉及注释标签；当前刑的有向配对没有因此发生错误。[《三命通会》卷二《论三刑》](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷02)。

## 对 Core 领域边界的最终判断

阴阳、正五行、天干、地支、六十甲子及其固定关系具备清楚的共享价值。十神、长生、藏干虽不能默认代表所有数术，但不能仅因需要观察主体或采用规则就把现有模型全部排除。当前最需要补齐的是**每个固定查询究竟采用什么定义**，而不是改名、抽出 `rules` 模块或添加一套策略框架。

目前已明确的边界应保留：五合对应不等于成化、三合成员不等于成局、三刑配对不等于刑已发动、长生阶段不等于旺衰、旬空不等于实际失效、纳音五行不等于完整取象、遁干不等于历法边界。真正需要优先修订的是本报告列出的藏干槽位定义和六破采用范围，并纠正此前三刑名称的审查记录。
