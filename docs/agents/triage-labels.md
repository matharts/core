# 将技能角色映射到分诊标签

技能提到分诊角色时，使用下表对应的 GitHub 标签。当前五个角色与标签同名；以后重命名标签时，只修改第二列映射。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可由 Agent 实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |
