# MathArts Core 当前设计与后续准入

2026-10-04：全库采用当前公共契约，取消向后兼容。实现与验证见[清理记录](breaking-cleanup.md)，公共变化见[API 与编码说明](migration.md)。此前审查报告保留为历史证据，不代表当前实现或当前测试结果。

## 边界

Core 承载跨数术共享的有限领域值、周期操作和明确采用的固定关系。日期换算、历法归属、排盘、起卦、流派策略与实际成局、成化、吉凶由对应领域库承担。

准入按具体语义分开评估身份、固定对应、流派映射和应用条件。名称相同不自动证明跨体系语义相同；现有固定表也不能由测试通过推定已完成文献核验。具体消费场景、来源、版本、同输入对照及差异以[规则边界](rules.md)为准。

## 当前模块

| 模块 | 职责与公共入口 |
| --- | --- |
| `math/ring` | `CyclicRing`、严格索引、周期步进与正向距离；周期由 `NonZeroU8` 保证非零 |
| `primitive`、`element` | 阴阳、五行及有向生克关系 |
| `stem`、`branch` | 天干、地支、固有属性与明确命名的固定关系 |
| `sexagenary` | 合法六十甲子构造、索引、步进；`xun()`、`nayin()` 返回身份 |
| `xun` | 六旬身份、旬首、十成员、归属与缺位查询 |
| `nayin` | 三十纳音身份、名称、五行及对应干支对 |
| `three_combination`、`three_meeting` | 三合、三会（限定方合）完整三支身份、成员、五行及无序识别 |
| `trigram`、`hexagram` | 八卦及六爻结构、有界爻位、结构修改与变换 |
| `god`、`growth`、`stem_derivation` | 明确采用的十神、长生及天干推导；跨体系证据缺口逐项记录 |
| `error` | 索引、干支配对和中文解析错误 |

旬和纳音查询归属各自身份类型。完整组不保留旧三合伙伴元组；纳音不保留与身份入口并行的五行返回接口。crate 根和领域模块提供当前正式导出，不提供旧名字别名。

## 公开契约

- 严格索引构造与周期回绕分开；有限爻位不回绕。全部 `i32` 步进使用宽整数安全约减。
- 干支仅允许同阴阳配对，解析与反序列化经过同一不变量检查。
- 关系保留方向；成员排序与身份编号不表示强弱或吉凶。
- 中文文本与机器代码分开；爻数组自下向上，低位为初爻，阳为 1、阴为 0。
- 成员数组和错误对象无需堆分配，库无条件 `no_std`、禁止 unsafe。
- 默认特性为空，只有可选 `serde`；不提供 `std` 兼容开关。
- 可读 Serde 枚举仅接受代码字符串，记录仅接受具名对象；拒绝旧 `residual`、unit 对象、记录数组和未知／重复／缺失字段。
- 不承诺旧 API 或旧数据兼容。协议变更明确记录，更新有版本的独立样本；不通过往返测试或默改预期隐藏行为变化。

## 验证

hooks 与 CI 的配置分别以 [hk.pkl](../hk.pkl) 和 [ci.yml](../.github/workflows/ci.yml) 为准。Serde 关闭／开启 × debug／release 共四组行为测试，公共示例同样实际运行四组；另执行格式、严格 Clippy、严格 rustdoc 与两组 `thumbv7m-none-eabi` 库构建。

有限域按独立预期穷举：干支 120 对中恰好 60 个合法值，旬与纳音完整覆盖六十甲子；三合、三会各识别 1728 个有序输入；八卦与六爻结构覆盖 8、64 个值。机器编码以 [encoding-v2.json](../tests/fixtures/encoding-v2.json) 及各领域样本为基准，正例与拒绝项分别验证。样本缺失、缩水或测试未执行必须失败。

本地验证不代替远端 CI；裸机构建不代表硬件运行；模型 token 不证明任意二进制格式的字节兼容；技术检查不补足领域来源证据。

## 后续工作

先补齐现有“证据待补”关系的具体消费体系对照与影印校勘，再决定规则归属。对旬、纳音及候选新能力继续采用同样的逐项准入标准；不会因为当前类型已实现而自动宣布全体系通用。

保持 Core 的有限领域范围。历法、排盘、占断和领域流派实现分别在对应库设计，新增范围需有具体消费目标与独立验收契约。
